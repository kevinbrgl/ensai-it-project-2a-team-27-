- `█` / 🟪 : barre violette (tâches).

- Les lignes de phase n'ont pas de dates propres, elles servent de séparateurs.
- Le Markdown ne permet pas de remplir une cellule en couleur dans un bloc de texte : le rouge y est donc rendu par le symbole `▓` (et par 🟥 dans les tableaux). Les dates, elles, sont exactement celles du fichier Excel.
